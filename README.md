# סטודיו רעיונות: אבטיפוס מסך בית

אבטיפוס חזותי לאפליקציה לסטודנטים בקורס **Design Thinking for L&D**.

## מבנה הקבצים

```
public/
  index.html   ← התוכן והמבנה של הדף (טקסטים, כרטיסיות, פרויקטים)
  styles.css   ← העיצוב: צבעים, גדלים, פריסה, התאמה לטלפון
  script.js    ← ההתנהגות: הודעת "יהיה זמין בקרוב" בלחיצה על כפתורים
```

התיקייה נקראת `public` כי זו התיקייה ש-Firebase Hosting מפרסם כברירת מחדל.

## איך משנים?

| רוצה לשנות… | איפה? |
|---|---|
| טקסט, כותרת, שם פרויקט | `index.html`: כל אזור מסומן בהערה כמו `1. אזור עליון` |
| צבעים בכל האתר | `styles.css`: המשתנים בראש הקובץ (`--teal-dark`, `--yellow`…) |
| מראה בטלפון | `styles.css`: החלק `התאמה למסכים קטנים` בסוף הקובץ |
| הודעת "יהיה זמין בקרוב" | `script.js` |
| צורת הפרח | `index.html`: ה-`<symbol id="flower">` בתחילת הדף |

## איך צופים?

פותחים את `public/index.html` בדפדפן (לחיצה כפולה על הקובץ).
